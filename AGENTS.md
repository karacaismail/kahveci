# Espresso Atlası proje kararları

- 22 Ekim güncellemesi: Mantine, korunmuş masaüstü Chrome + ayrı telefon yerleşimi. Tablet mevcut masaüstüdür. Telefon başlangıç profili screen kısa kenarı<600 CSS px, any-pointer:coarse ve maxTouchPoints>0 birlikte seçilir; UA/cihaz adı kullanılmaz. Yatay çevirme ve dar desktop pencere profil değiştirmez. 320/360/375/390 ve yatay telefon test edilir. Mobil fiziksel cihaz/Safari doğrulaması ayrıca raporlanır.
- UI fontu Outfit; görünür metin en az 14 CSS px. Renk/yüzey/boşluk/odak/hareket tokenları `src/styles.css` ve `src/motion.ts` içindedir. Kütüphane stilleri tema ve ortak adapter üzerinden uyarlanır.
- Normal temada çevreleyen odak halkası yok. Yalnız Tab/Shift+Tab merkezi klavye modunu açar; pointer/touch kapatır. Görünür alternatif düz alt çizgidir. Forced colors + klavye modu + focus-visible dar istisnası 2px CanvasText outline.
- Hareket 180 ms, simetrik cubic-bezier(.65,0,.35,1); giriş/çıkış aynı tokenları kullanır. Mantine Modal, Select, Tooltip adapterları aynı kaynağa bağlıdır. Reduced-motion ayrı istisnadır. Normal componentte yerel easing/süre yazmayın.
- Yuvarlatılmış yüzeyin kenarında renkli vurgu şeridi kullanılmaz. Mantine Notification varsayılan şeridi kaldırılmıştır.
- `catalog.json` kaynaklı alanları `verified` (alan → URL), varsa `evidenceKind`, exact varyant notları ve teklif kanıt türüyle saklar. Aktarılan eski alanlar kesin özellik değildir. Genel marka/aile satırına farklı SKU'nun donanımı sessizce yazılmaz. Eski öznel kalite puanları karar motoruna alınmaz.
- `boilerArchitecture` yalnız kaynaklı kazan tanımından türetilir; kaynak URL'si yanında tutulur. Kahve/buhar iş yükü ticari kapasite garantisi değildir.
- Teklif fiyatları gözlem görüntüsüdür; arama indeksi ve sayfa kaydı ayrılır. Stok dışı/uyumsuz ürün en düşük uygun teklif hesabına girmez. Koşullu kampanya görünür olmalıdır. Kargo/ödeme fiyatı doğrulanmadan canlı en ucuz iddiası kurulmaz.
- Görseller üretici/satıcı kaynağından yüklenir. Gerçek ürün fotoğrafı yerine AI/temsili makine görseli veya aynı fotoğrafın yeniden boyutlandırılmış kopyalarını ayrı açı diye eklemeyin. Başarısız kaynaklar için yerel indirme/proxy ile erişim engeli aşmayın.
- Karşılaştırma en fazla dört makine; seçim localStorage'da yalnız ürün ID'leriyle tutulur. Öğütücü/süt/aksesuar verisi ayrı alandadır. React componentlerini parent render içinde tanımlamayın; karşılaştırma ve modal değişimleri odağı/galeri seçimini kaybettirmemelidir.
- Girdi veya ekipman fiyatı bilinmiyorsa eksiksiz set toplamı uydurulmaz. Yarı otomatikte ayrı öğütücü, entegre sistemde dahil öğütücü ayrımı korunur. Tercih puanları editoryal kurallardır; ölçülmüş tat puanı değildir. Fiyat ve bütçe puana veya kabul şartlarına girmez.
- İlgili komutlar proje dizininden: `npm run check` (formatter + domain/veri/policy testleri + TypeScript ve production build), `npm run preview -- --port 4173`, `npm run test:browser` (kurulu Chrome, izole headless profil), `node tests/gallery-audit.mjs` (kaynak görsellerin gerçek tarayıcı yüklemesi). Browser testi varsayılan olarak 127.0.0.1:4173'e bağlanır; `ATLAS_URL` değişebilir.
- Kişisel Chrome profili/sekmesi kullanılmaz. Otomatik test kurulu Chrome binary'siyle ayrı geçici profil açar. Gerçek çalışan kontroller pass/fail; çalışmayanlar not_run olarak bildirilir. Production URL ile dev URL ayrılır.
